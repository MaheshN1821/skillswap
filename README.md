# SkillSwap - A peer-to-peer learning platform where users exchange skills and knowledge.

## Overview
SkillSwap is an innovative skill-exchange platform where users can teach skills they know and learn new ones from others. Featuring a user dashboard, integrated session scheduling, and feedback systems, it promotes collaborative learning and knowledge sharing in a user-friendly environment. 
Website Link : https://skill-swap-ebon-beta.vercel.app/

## Features      
- Developed a MERN stack skill exchange platform where users can both teach and learn skills using a point-based reward system.
- Integrated Google Meet for scheduling 1:1 live teaching sessions, allowing users to generate and share meeting links directly within the platform.
- Built personalized dashboards for managing upcoming and past sessions, skill listings, and learning activities.
- Implemented feedback and rating system after lessons to maintain quality and accountability among users.
- Added profile reporting and moderation tools to ensure trust and safety within the community.
  
## Technologies Used
- React
- Tailwind CSS
- Node.Js
- Express
- Mongo DB
- Jwt-Auth
- Vercel

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/MaheshN1821/skillswap.git
   ```
2. Navigate to the project directory:
   ```sh
   cd skillswap
   ```
3. Navigate to the frontend directory by creating a new terminal:
   ```sh
   cd client
   ```
4. Install the dependencies:
   ```sh
   npm install --legacy-peer-deps
   ```
5. Start the development server:
   ```sh
   npm run dev
   ```
6. Navigate to the backend directory by creating a new terminal:
   ```sh
   cd server
   ```
7. Install the dependencies:
   ```sh
   npm install --legacy-peer-deps
   ```
8. Start the server:
   ```sh
   npm start
   ```
9. Remember to create a APP PASSWORD for your preferred email id, and these variables in your .env file : PORT,MONGO_URL,SEC_ACC,SEC_REF,EMAIL_PASS with appropriate values!
